Arquitetura: O Journey Completo do Aluno ISR

Objetivo: Mapear cada passo da experiência do aluno — desde a compra no systeme.io até usar a app PWA diariamente.

1. O Fluxo Completo (Visão 30.000 pés)

Compra (systeme.io)
↓
Email de Confirmação + link
↓
Landing Customizada (bem-vindo)
↓
Autenticação (login/senha ou link mágico)
↓
App PWA (home com próximo passo claro)
↓
Uso diário (aulas, exercícios, Flin, comunidade)

2. Passo a Passo Detalhado da Experiência

🛒 Passo 1: Compra no Systeme.io

O que aluno faz:

  • Escolhe o curso/ciclo
  • Preenche dados (nome, email, telefone)
  • Completa pagamento

O que acontece no backend:

  • Systeme.io cria registro de aluno
  • Sistema ISR recebe webhook do systeme.io com dados: nome, email, qual ciclo/nível
  • ISR cria usuário na base de dados (status: "novo", ativo)
  • Gera credenciais temporárias (login/senha OU link mágico único)

Experiência do aluno:

✅ Compra confirmada! Em segundos, recebe email: "Bem-vindo à ISR! Clique aqui para acessar sua área"

📧 Passo 2: Email de Confirmação + Link de Acesso

Email contém:

  • Saudação personalizada ("Olá, João!")
  • Resumo: "Você se inscreveu em [Curso/Ciclo]"
  • CTA principal: "🚀 Acessar minha área" → link para landing customizada
  • Ou: email com login/senha (se optar por esse método)
  • Rodapé: "Dúvidas? Contate: suporte@..."

O link redireciona para: `https://inglessemroteiro.netlify.app/welcome?token=ABC123`

Experiência do aluno:

✅ Email chega em segundos, com branding ISR claro, CTA óbvio

🔐 Passo 4: Autenticação & Login

Método 1: Token Mágico (Recomendado)

  • Aluno clica link no email → token leva para landing
  • Landing valida token → cria sessão (cookie seguro)
  • Redireciona para home, já autenticado
  • Nenhuma senha para digitar — frictionless

Método 2: Login/Senha (Fallback)

  • Se link expirar ou aluno perder email, pode fazer login tradicional
  • Email + senha recebida no email inicial

Método 3: SSO com Google/Apple (Futuro)

  • "Continue com Google" — mais simples ainda
  • Implementar depois que fluxo principal estiver sólido

Experiência do aluno:

✅ Clica link → entra na app. Rápido, fácil, sem fricção. (Ou faz login se precisar.)

4. PWA: Por Que É Ideal Para ISR

PWA = Progressive Web App — webapp que funciona como app nativo no celular.

Benefícios para alunos:

  • ✅ Instala no home screen: Ícone ISR na tela inicial (parece app nativa)
  • ✅ Funciona offline: Se internet cair, aluno ainda consegue revisar conteúdo já baixado
  • ✅ Rápida: Cache inteligente = app abre em milissegundos
  • ✅ Sério: Não parece "um website" — parece educação profissional
  • ✅ Sem app store: Não precisa de iOS/Android publishing — atualiza sozinha
  • ✅ Notificações: Push notifications (aula em 30 min, exercício pendente, etc)
  • ✅ Economiza dados: Cache local = usa menos banda (importante para Brasil)

Experiência do aluno:

✅ Toca ícone ISR na home → app abre como app nativa. Rápida, confiável, funciona offline. Sente que é "seu app".

6. Decisões Importantes (Para Você Decidir)

A. Autenticação: Token Mágico vs. Login/Senha?

Token Mágico (Recomendado):

  • ✅ Sem fricção (1 clique, entra direto)
  • ✅ Menos problemas com senha esquecida
  • ⚠️ Token expira — aluno precisa usar logo depois da compra

Login/Senha:

  • ✅ Funciona sempre (aluno pode digitar qualquer hora)
  • ⚠️ Mais fricção (aluno digita email + senha)
  • ⚠️ Esquece senha? Precisa fazer reset

Minha recomendação: Token Mágico + Fallback para Login/Senha

  • Email com token (frictionless)
  • Se aluno perdeu email, pode fazer login tradicional
  • Melhor dos dois mundos

B. Notificações: Push vs. Email?

Push (Alunos já instalou app):

  • ✅ Mais imediato e visível
  • ✅ Aumenta frequência de abertura da app
  • ⚠️ Aluno precisa autorizar (pode recusar)

Email:

  • ✅ Sempre chega (não depende de autorização)
  • ⚠️ Pode ser ignorado, spam

Minha recomendação: Ambos, mas priorizando Push

  • Notificação push para tempo-sensível (aula em 30 min)
  • Email para resumo semanal (exercícios pendentes, certificado próximo)

C. Caderno: Dentro da App ou Link Externo?

Dentro da App (integrado):

  • ✅ Fluxo fluido (aula → clica "exercício" → vai direto no caderno)
  • ✅ Melhor UX (tudo em um lugar)
  • ⚠️ Precisa migrar cadernos do Google Docs para database ISR

Link Externo (Google Docs):

  • ✅ Sem mudança de infraestrutura (continua como está)
  • ⚠️ Aluno sai da app, perde contexto
  • ⚠️ Não é integrado (não vê progresso do exercício na app)

Minha recomendação: Começar com Link Externo, migrar para Integrado depois

  • Fase 1: App com links para Google Docs (mais rápido)
  • Fase 2: Migrar cadernos para ISR (quando tiver mais tempo)
