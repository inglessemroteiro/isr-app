1. Dados Dinâmicos: Como Conectar com Sua Base

Cenário Atual

Você tem dados em algum lugar (Google Sheets? Airtable? Banco SQL?). A home da app atualmente tem dados hardcoded:

state = {
  upcomingClass: { name: "Speaking...", time: "19h00", ... },
  progress: { percentage: 60, aulas: { completed: 6, total: 10 } },
  // etc
}

O que precisa virar dinâmico:

  • ✅ Nome do aluno (João, Maria, etc)
  • ✅ Nível (Basics, Essentials, Speaking Group, Advanced)
  • ✅ Próxima aula (qual, quando, professor)
  • ✅ Progresso (quantas aulas fez, exercícios, desafios)
  • ✅ Exercícios pendentes (com prazos)
  • ✅ Aulas extras (quais estão acontecendo)
  • ✅ Atividades recentes

Opção 1: Google Sheets → API → App (Recomendado para começar)

Vantagem: Rápido, você já usa Sheets, sem precisar de banco de dados complexo

Fluxo:

Google Sheets (tabelas de alunos, aulas, exercícios)
         ↓
   Google Apps Script
         ↓
   API HTTP (você hospeda em Apps Script)
         ↓
   App ISR (fetch dados em componentDidMount)
         ↓
   Home renderiza dinâmico

Como fazer:

  1. Organize suas Sheets:
    • Aba "Alunos": ID | Nome | Email | Nível | CycleStartDate | CycleEndDate
    • Aba "Aulas": ID | Date | Time | Professor | Level | Topic | MeetLink
    • Aba "Exercícios": ID | Name | Level | Deadline | AssociatedLesson
    • Aba "ProgressoAluno": AlunID | AulaID | Presente | ExercícioID | Status
  2. Crie Apps Script (Google):
    • Extensions → Apps Script
    • Código que lê Sheets e expõe endpoint HTTP
  3. Exemplo de Apps Script: 
function doGet(e) {
  const alunId = e.parameter.alunId;
  const sheet = SpreadsheetApp.getActiveSpreadsheet();
  
  // Busca aluno
  const alunosRange = sheet.getSheetByName("Alunos").getRange("A2:E");
  const alunos = alunosRange.getValues();
  const aluno = alunos.find(row => row[0] == alunId);
  
  // Busca progresso
  const progressoRange = sheet.getSheetByName("ProgressoAluno").getRange("A2:D");
  const progresso = progressoRange.getValues().filter(row => row[0] == alunId);
  
  // Busca próxima aula
  const aulasRange = sheet.getSheetByName("Aulas").getRange("A2:F");
  const aulas = aulasRange.getValues();
  const proxAula = aulas.find(row => new Date(row[1]) > new Date());
  
  return ContentService.createTextOutput(JSON.stringify({
    aluno: { nome: aluno[1], nivel: aluno[4] },
    progresso: { aulas: progresso.length, ... },
    proxAula: { ... }
  })).setMimeType(ContentService.MimeType.JSON);
}
  • Na app, fetch os dados: 
    • componentDidMount() {
  const alunId = this.props.alunId; // vem do login/URL
  fetch(`https://script.google.com/macros/d/YOUR_SCRIPT_ID/usercontent?alunId=${alunId}`)
    .then(res => res.json())
    .then(data => this.setState(data))
    .catch(err => console.error(err));
}

    Opção 2: Firebase Firestore (Melhor para escala)

    Vantagem: Real-time, escalável, seguro, integra com auth

    Fluxo:

    Firebase Firestore (coleções: users, aulas, exercicios, progresso)
         ↓
   App ISR (SDK Firebase)
         ↓
   Real-time listeners (componentDidMount)
         ↓
   Home renderiza dinâmico + ao vivo

    Código exemplo:

    import { initializeApp } from 'firebase/app';
import { getFirestore, collection, query, where, onSnapshot } from 'firebase/firestore';

const app = initializeApp({ apiKey: '...', projectId: '...' });
const db = getFirestore(app);

componentDidMount() {
  const alunId = this.props.alunId;
  const q = query(collection(db, 'users'), where('id', '==', alunId));
  
  onSnapshot(q, (snapshot) => {
    const aluno = snapshot.docs[0].data();
    this.setState({ aluno });
  });
}

    Minha recomendação: Comece com Google Sheets + Apps Script (mais rápido, menos curva). Migre para Firebase depois se precisar de escala.

    2. PWA: Tornar App Instalável no Celular

    O que é PWA? Webapp que funciona como app nativa. Aluno instala um ícone na home do celular, app abre rápido, funciona offline.

    Passo 1: Criar `manifest.json`

    Arquivo que define o ícone, nome, cores da app:

    {
  "name": "Inglês sem Roteiro",
  "short_name": "ISR",
  "description": "Sua área de aluno ISR",
  "start_url": "/",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#ffffff",
  "theme_color": "#164951",
  "icons": [
    {
      "src": "/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "/icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}

    Onde colocar: Na raiz do seu projeto (mesmo nível que index.html)

    Passo 2: Referenciar no HTML

    Adicione na <head> do seu index.html:

    <link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#164951">
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
<link rel="apple-touch-icon" href="/icon-192.png">

    Passo 3: Service Worker (para offline + cache)

    Arquivo `service-worker.js` que faz cache inteligente:

    const CACHE_NAME = 'isr-v1';
const urlsToCache = [
  '/',
  '/index.html',
  '/styles.css',
  '/app.js'
];

// Install: fazer cache dos arquivos
self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME).then(cache => {
      return cache.addAll(urlsToCache);
    })
  );
});

// Fetch: usar cache se offline
self.addEventListener('fetch', event => {
  event.respondWith(
    caches.match(event.request).then(response => {
      return response || fetch(event.request);
    })
  );
});

    Registrar no app (componentDidMount):

    if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/service-worker.js');
}

    Passo 4: Testar no Android/iOS

    • Android: Abra app no Chrome → menu (⋯) → "Instalar app"
    • iOS 15.1+: Safari → compartilhar → "Adicionar à Tela de Início"

    Resultado

    Aluno abre app → parece app nativa (sem URL bar, sem menu do navegador) → rápida + offline

    3. Notificações Push: Avisar Aluno

    Casos de uso:

    • 🔴 "Sua aula começa em 30 minutos!"
    • ⏰ "Exercício vence amanhã"
    • 🎉 "Parabéns! Você atingiu 50% do ciclo"
    • 💬 "Alguém respondeu seu desafio"

    Opção 1: Firebase Cloud Messaging (FCM) — Recomendado

    Fluxo:

    1. App pede permissão: "Receber notificações?"
    2. Aluno clica "Sim"
    3. Firebase gera token único para esse aluno
    4. App envia token para seu backend
    5. Seu backend (ou Google Cloud Functions) envia notificações para tokens específicos

    Exemplo: Registrar para notificações

    import { getMessaging, getToken, onMessage } from 'firebase/messaging';

const messaging = getMessaging();

// Pedir permissão
Notification.requestPermission().then(permission => {
  if (permission === 'granted') {
    // Pegar token
    getToken(messaging, { vapidKey: 'YOUR_KEY' }).then(token => {
      console.log('Token:', token);
      // Enviar token para seu backend
      fetch('/api/saveToken', { 
        method: 'POST', 
        body: JSON.stringify({ alunId, token }) 
      });
    });
  }
});

// Receber notificações quando app está aberta
onMessage(messaging, (payload) => {
  console.log('Notificação:', payload);
  // Mostrar notificação no app
});

    Exemplo: Enviar notificação (do seu backend)

    // Node.js + Firebase Admin SDK
const admin = require('firebase-admin');

admin.initializeApp();

const message = {
  notification: {
    title: '🔴 Sua aula começa em 30 minutos!',
    body: 'Speaking & Storytelling com Agatha'
  },
  data: {
    link: '/aulas/speaking-storytelling'
  }
};

admin.messaging().sendToDevice(userToken, message);

    Opção 2: OneSignal (Mais simples, pré-construído)

    Vantagem: Dashboard visual para enviar notificações, segmentação por nível/turma

    Fluxo:

    • Crie conta OneSignal
    • Integre SDK no app (2 linhas)
    • Dashboard OneSignal: clique "Send Notification" → selecione alunos → envie

    Minha recomendação: Comece com OneSignal (mais rápido). Migre para Firebase depois se quiser automatizar.
